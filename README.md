# AI VIDEO CALC v2

Mobile-first PWA-калькулятор себестоимости генерации видео в Kling AI и через SYNTX. Приложение считает одну генерацию, проектную смету с запасом на перегенерации и фактический расход. Работает как статический сайт без сервера и базы данных.

## Архитектура

- `index.html` — доступная разметка интерфейса.
- `css/app.css` — mobile-first стили и адаптация для desktop.
- `js/calculator.js` — чистая расчётная логика без привязки к DOM.
- `js/pricing.js` — загрузка `pricing.json`, сетевое обновление и fallback на локальный кэш.
- `js/app.js` — состояние интерфейса, localStorage, импорт/экспорт и PWA-регистрация.
- `data/pricing.json` — единая тарифная база.
- `manifest.webmanifest` и `sw.js` — установка и offline-режим.
- `scripts/validate-pricing.mjs` и `tests/calculator.test.mjs` — безопасные проверки данных и расчётных типов.

## Тарифная база

`data/pricing.json` отделяет провайдеров, модели, варианты и биллинг от интерфейса. Для каждого варианта указываются разрешение, аудио, допустимая длительность, статус и источник либо пояснение.

Поддерживаемые типы биллинга:

- `rate_per_second` — количество credits/tokens в секунду;
- `duration_table` — таблица стоимости для разрешённых длительностей;
- `fixed_generation` — фиксированная стоимость генерации;
- `manual_required` — публичный тариф не подтверждён, расход вводит пользователь.

Чтобы добавить модель, создайте запись в `models`, укажите существующий `provider`, уникальный `id` и массив `variants`. Чтобы добавить тип биллинга, реализуйте отдельную ветку в `billableUnits()` и тест в `tests/calculator.test.mjs`; UI использует общий результат и не требует переписывания.

## Достоверность данных

- `verified` — ставка сверена с указанным официальным источником;
- `manual` — значение перенесено из v1.2 либо задаётся пользователем;
- `unverified` — модель известна, но публичная ставка не подтверждена.

Пакеты Kling `10 $ / 660 credits` и SYNTX `1690 ₽ / 680 tokens`, а также старые ставки SYNTX перенесены из v1.2 и помечены `manual`. Подтверждённые ставки Kling 3.0 помечены `verified`; неподтверждённые 4K и большинство каталога SYNTX не угадываются и используют `unverified`/`manual_required`.

## Обновление тарифов

Кнопка «Обновить pricing.json» запрашивает свежий относительный файл GitHub Pages без кэша. При ошибке используется последняя копия из localStorage, а service worker хранит рабочий набор ресурсов offline. Workflow `.github/workflows/check-pricing.yml` только проверяет структуру и контрольные значения: он не переписывает цены и не запускает ненадёжный scraper.

## Локальный запуск

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/`. Для установки PWA нужен HTTP(S), поэтому открытие `index.html` через `file://` не подходит.

Проверки выполняются без сторонних зависимостей:

```bash
npm test
npm run check
```

## Локальные данные

Курс USD/RUB, параметры пакетов, ручные расходы SYNTX, проект и процент запаса сохраняются в localStorage. Экспорт и импорт используют JSON. При первом запуске v2 приложение переносит курс и параметры пакетов из ключей v1.2, если они существуют.

Service worker v2 использует новый cache name и удаляет старые кэши при активации, поэтому v1.2 не должна оставаться на экране после обновления.
