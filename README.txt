AI PRICE КАЛЬКУЛЯТОР by avlasevi4.ai — v1.1

В этой версии интегрирована финальная иконка приложения:
- favicon для браузера;
- apple-touch-icon;
- PWA icons 192x192 и 512x512;
- maskable icon для установки приложения.

Как опубликовать PWA на GitHub Pages:
1. Распакуйте архив.
2. Загрузите содержимое папки в репозиторий.
3. Включите GitHub Pages для ветки/main папки root.
4. Откройте публичную HTTPS-ссылку.
5. В браузере появится возможность установить приложение как PWA.

Важно: установка PWA обычно не работает при открытии через file://. Для установки нужен HTTPS или localhost.
