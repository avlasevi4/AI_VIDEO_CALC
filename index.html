Свой сервис и модели

Создайте сервис с собственной ценой токена. Для каждой модели и режима задайте контрольную длительность и расход токенов — калькулятор определит расход за секунду.

Своя база
Без входа собственные сервисы сохраняются в этом браузере; после входа владельца синхронизируются с облаком.

Ручные тарифы моделей

Введите расход токенов для конкретной длительности. Пользовательское значение заменит базовый тариф только для этой комбинации модели, режима и времени.

База: —
После входа тарифы синхронизируются с личным облаком и будут одинаковыми на всех ваших устройствах.

Данные

Повторно загружает встроенный файл тарифов с GitHub без кэша. Проекты и ваши пользовательские настройки остаются без изменений.
Экспорт сохраняет резервную копию проектов, настроек, ручных тарифов и собственных сервисов. Импорт восстанавливает её на этом или другом устройстве.
Файл тарифов не содержит проекты, почту или данные входа. У владельца в него включается Dreamina Plus; у получателя она появится как вручную установленный сервис.
Очищает данные только в этом браузере. Облачные проекты и тарифы владельца не удаляются.
